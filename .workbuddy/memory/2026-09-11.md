# 2026-09-11

## 新建项目：Capi（参考 runapi.ai 复刻）

**目标**：以 runapi.ai 为参考做一个 AI 模型聚合 API 平台「Capi」。范围＝核心站点，界面与文档尽量复刻；
不做 playground 的真实生成交互；技术栈＝Node 生态 + shadcn/ui。

**技术选型**
- Next.js 16.3.4（App Router / Turbopack）+ React 19 + TypeScript + Tailwind CSS v4。
- shadcn/ui：CLI `init` 被沙箱 SIGKILL，改为**手动配置**（`components.json` + `lib/utils.ts` + 手写
  `components/ui/*`），依赖走 radix 分包。结论：shadcn 组件本身就是复制进项目的源码，手动装配等价。
- 文档渲染：`react-markdown` + `remark-gfm` + `rehype-slug`，配自定义组件映射
  （`pre` → CodeBlock、`blockquote` → 浅蓝 Callout、表格 → Table）。
- 代码高亮：`highlight.js/lib/core` 按语言注册（避免全量包），token 配色对齐参考站的深色编辑器风格。

**架构要点**
- 路由分组：`(marketing)`（带 Header/Footer）、`(auth)`（登录注册）、`(app)`（dashboard）、`docs`（独立三栏壳）。
- 内容层：`lib/models-data.ts`（48 个模型族 / 约 130 个模型 ID）、`lib/api-spec.ts`（41 个端点，结构化数据驱动
  渲染，避免手写数百篇 MDX）、`content/docs/**/*.md`（25 篇，guides 6 + resources 19）+ 自写 frontmatter 解析。
- Mock API：`/api/v1`（chat completions 含 SSE 流、images、kling task、tasks/[id]、models、me/balance），
  内存态任务生命周期 pending→processing→completed，Bearer 鉴权失败返回 401。

**踩坑**
- Editor 对同一文件的连续 Edit 偶发不落盘，改完必须 `grep`/`Read` 复核再 build。
- Next 16 的 `next.config.ts` 改动 `devIndicators: false` 可去掉左下角 dev 徽标，截图时更干净。
- react-markdown 的 `code` 组件只在 fenced block 内出现 `language-*` 类；块级处理要挂在 `pre` 上。

**验证**：`eslint` 0 error；`next build` 通过（50 个模型页 + 41 个 API 页 + 25 个文档页 SSG，营销页静态）。
